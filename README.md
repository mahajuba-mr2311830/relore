# Relore

Relore is a managed marketplace for pre-owned clothing in Qatar, available as a mobile app and a website. Private sellers list their clothing, the Relore team reviews every listing by hand, and Relore's own drivers collect each item from the seller and deliver it to the buyer.

This repository holds the group project for CMPS307 (Introduction to Project Management).

## Try the prototype

Download or clone the repository, then open `part4-output/prototype/index.html` in a browser. No installation is needed. It shows sample data only and takes no real payments.

## Fees used throughout

- Commission: 20% of the sale price, deducted from the seller's payout.
- Delivery fee: QAR 15 + QAR 0.80 per km of road distance, paid by the buyer at checkout.
